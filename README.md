# CHOPIN BMF — full rebuild from empty outputs

The package is designed so that `data/`, `results/`,
`manuscript/figures/` and `manuscript/tables/` **may start empty**. The
analysis **does not** require any previously calculated `.rds`, `.rda`,
figure or table.

## Required inputs (not generated by this package)

1.  R \>= 4.1 with dplyr \>= 1.1; packages: `chopin.data`, `tidyverse`,
    `Btrait`, `readxl`, `janitor`, `survival`, `usethis`, `ggrepel`,
    `scales`, `tidytext`, `lubridate`. Optional: `writexl`, `flextable`,
    `officer`, and the manuscript rendering dependencies `officedown`,
    `knitr`, `rmarkdown`.
2.  The installed **source-data** package `chopin.data`, including
    datasets `soles_contam`, `benthos_contam`, `soles_stomach`,
    `soles_G0_pools_biometrics`, `contam_info`, and `species_classif`.
    The codebase previously used
    `pak::pak("FlorenceMounier/chopin.data")`. Pin its actual
    version/commit before publication.
3.  The source workbook `inst/extdata/Gogina_data-2021-0002-01.xlsx`.

A package with literally NO source data cannot generate the analysis.
The rebuild is from empty *derived output folders*, using the supplied
source data.

## Run once, from the project root

``` r
source("data-raw/00_RUN_ALL_FROM_SCRATCH.R")
```

All scripts run in independent R environments. `00_CHOPIN_preflight.R`
checks only source dependencies. Scripts 01–08 produce the downstream
files in order:

| Stage | Input | Main output |
|----|----|----|
| 00 | Source package + Gogina workbook + settings | `results/source_configuration.txt` |
| 01 | `chopin.data` chemical data | `results/scenarios.rds`, `results/prey.rds`, `data/*.rda` |
| 02 | Stomach data + mass references + `prey.rds` | `results/prop_diet.rds`, mass/coverage outputs |
| 03 | Scenarios + diet | `results/bmf_compare.rds`, sensitivities and figures |
| 04 | Same saved MLE imputations + BMFs | gamma vs lognormal comparison and QA |
| 05 | Source samples + scenarios | Supplementary sampling inventory |
| 06–08 | Freshly generated outputs 01–04 | Additional reviewer sensitivity analyses |
| 10 | Newly generated outputs + source data | Post-run provenance validation |
| 09 | Validated outputs | **Optional** immutable submission snapshot |

`data-raw/09_CHOPIN_checked_submission_snapshot.R` is **not run by
default**: review the results and manuscript first. To include it in the
orchestrated run, set `run_all(include_snapshot = TRUE)` at the end of
`00_RUN_ALL_FROM_SCRATCH.R`.

## Package data vs intermediate analytical outputs

`saveRDS(x, "results/x.rds")` saves reproducible intermediate results;
`usethis::use_data(x, overwrite=TRUE)` writes `data/x.rda` for
packaging. Both are generated during scripts 01–03 when
`SAVE_TO_PACKAGE <- TRUE` in the central configuration. No `data/*.rda`
file should be present initially.

The legacy_scripts_original/ directory preserves the supplied original
scripts for traceability, but they are NOT part of the execution chain.
The bundle also preserves the supporting manuscript sources. **The R
pipeline has not been executed here** (R is not available in the
creation environment): run it and inspect any data-specific failures
before public release or manuscript submission.
